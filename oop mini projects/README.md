# Student Management System

## 1. Introduction
The Student Management System is a Java-based application developed to manage student records. It allows users to add, display, search, update, and delete student information through a menu-driven interface.

## 2. Problem Statement
Managing student records manually can be time-consuming and difficult. This project provides a simple system to organize and manage student details efficiently.

## 3. Objectives
- To store student information.
- To add and display student records.
- To search for students using roll numbers.
- To update existing student details.
- To delete student records.
- To understand practical Java programming concepts.

## 4. Technologies Used
- Programming Language: Java
- IDE: Visual Studio Code
- Data Structure: ArrayList
- Input Handling: Scanner

## 5. Features
1. Add Student – Enter roll number, name, course, and marks.
2. Display Students – View all stored student records.
3. Search Student – Find a student using their roll number.
4. Update Student – Modify an existing student's details.
5. Delete Student – Remove a student record.
6. Exception Handling – Handles invalid numeric input.

## 6. Object-Oriented Programming Concepts
- **Classes and Objects:** The Student class represents individual student records.
- **Encapsulation (basic data grouping):** Student details and their display method are grouped in a class. The fields are not private in this version.
- **Abstraction:** The menu provides simple operations without exposing their internal implementation.

## 7. Working of the Project
1. The program displays a menu.
2. The user selects an operation.
3. Student details are entered or searched using a roll number.
4. The program performs the selected operation.
5. The updated information is displayed.
6. The program continues until the user selects Exit.

## 8. How to Run the Project
1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   `javac StudentManagementSystem.java`

5. Run the program:

   `java StudentManagementSystem`

## 9. Conclusion
The Student Management System demonstrates how Java can be used to manage student records through a simple menu-driven application. It provides practical experience with classes, objects, ArrayList, loops, conditional statements, and exception handling.
